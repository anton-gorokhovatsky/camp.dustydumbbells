# Работа над сайтом

Смотрим сюда во время работы над интернет-проектами:
https://app.notion.com/p/gorokhovatsky/3a6777056402808bb79df09beedc4161

Текущий этап — полный перенос опубликованного сайта без редизайна.
Сохранять исходные тексты, фотографии, шрифты, композицию, порядок блоков,
расписание и состояние закрытого приёма заявок. Улучшения — отдельная задача.

Перед публикацией: `npm test`, визуальная проверка главной на широком и узком
экране, проверка галерей, меню и страницы privacy. После публикации проверить
успех GitHub Actions и `release.json` на GitHub Pages.
