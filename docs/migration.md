# Перенос от 7 октября 2026 года

## Объём

Источник: https://camp.dustydumbbells.com/ и связанная страница `/privacy`.
Назначение: https://anton-gorokhovatsky.github.io/camp.dustydumbbells/.

Сохранены оригинальные HTML, CSS и JavaScript Tilda, а также изображения и шрифты.
Сборка меняет только адреса сохранённых ресурсов и ссылку на политику для работы
под `/camp.dustydumbbells/`. Контроль обратной замены в `npm test` подтверждает,
что весь остальной HTML, включая тексты, inline-стили и inline-скрипты, совпадает.
Фотографии и шрифты проверяются по SHA-256 без перекодирования.

## Особенности исходника, сохранённые намеренно

- На исходном сайте уже показано сообщение «Прием заявок завершен,
  до встречи в следующем году!». Регистрация заново не открывалась.
- У бегущих строк сохранены исходные ссылки `#form`; в текущей опубликованной
  версии формы с таким якорем нет. Новый сценарий заявки не придумывался.
- Сохранены оригинальные размеры текста, адаптивные пороги, анимации и оформление.
- Карта использует Yandex Maps через исходный скрипт Tilda и требует сети.
- Сохранены исходные ссылки на сообщество, Telegram, Instagram, размещение,
  а также исходная публичная аналитика Tilda. Их доступность зависит от сервисов.
- Canonical и Open Graph URL сохраняют исходный домен: Pages пока служит копией.
- Сохранена исходная политика конфиденциальности без юридической редакции.
