# DD Camp — Анталья

Полный перенос [camp.dustydumbbells.com](https://camp.dustydumbbells.com/)
в [репозиторий GitHub](https://github.com/anton-gorokhovatsky/camp.dustydumbbells).
Снимок опубликованной версии от **7 октября 2026 года**.

**Сайт в GitHub Pages:** https://anton-gorokhovatsky.github.io/camp.dustydumbbells/

Основная страница — приглашение с местным светом и погодой, открытый прогноз,
фотозин, программа «Афиша», «Билет» с выбором отелей и путеводитель по беговой
Анталье. Подлинные фотографии и предварительная программа
**12–25 октября 2027 года**. Даты и активности перенесены по решению пользователя;
весной содержание и условия будут уточнены. Набор пока не объявлен.

Редакция на основе `7401b13` отклонена. Текущие выбранные разделы проходят
отдельную локальную доводку; общий выпуск разрешён пользователем 9 октября.
Сверка и границы — [общий выпуск](docs/release-all-2026-10-09.md).
Успешные проверки не заменяют просмотр всей страницы и исследование с людьми.

Исходная копия сохранена без содержательных изменений в `source/` и опубликована
для сравнения: https://anton-gorokhovatsky.github.io/camp.dustydumbbells/original/.
Политика конфиденциальности остаётся по прежнему адресу `/privacy/`.

## Локальный запуск

Нужен Node.js 22 или новее. Единственная зависимость — SunCalc 2.1.1,
которая рассчитывает солнце локально и копируется в сборку вместе с лицензией.

```sh
npm ci
npm run dev
```

Открыть http://localhost:4173/camp.dustydumbbells/.
Сервер использует тот же вложенный путь, что и GitHub Pages.
После изменения исходников повторить `npm run build` и обновить страницу.

```sh
npm test          # сборка, контроль оригинала, модель среды, контраст и содержание
npm run build    # только сборка в dist/
npm run preview  # просмотр уже собранного сайта
```

Для сравнения локальных вариантов после обычной сборки:

```sh
node experiments/calendar/build.mjs
node experiments/memories/build.mjs
node experiments/travel/build.mjs
```

Маршруты находятся в `/experiments/` под тем же базовым путём. В обычную
сборку Pages они не входят. Их контрольный шаблон `experiments/baseline.html`
сохраняет контекст сравнения после переноса выбранных разделов в главную.

## Структура

- `site/index.html` — каноническая главная; `/direction/` собирается из неё же.
- `site/direction/screen.css`, `screen.js` — общий материал, Museo/Akt, первый
  экран, погодная среда, навигация, перетасовка стопки и галерея.
- `site/direction/program-poster.css`, `memories-zine.css`, `travel-ticket.css`
  — выбранные композиции программы, фотозина и подготовки к поездке.
- `site/hotel-directory.js`, `site/data/hotels.json`, `site/direction/media/hotels/`
  — пять вариантов жилья и фотографии из их официальных источников.
- `site/running-guide.js`, `site/direction/travel-ticket.js` — открытый
  путеводитель, доступный выбор отелей и чтение датированного курса.
- `site/environment.js` — местная дата, солнце, четыре палитры, погодная модель,
  проверка давности данных и художественные погодные состояния.
- `site/fonts/` — локальные шрифты и их лицензии; текущий основной текст — Akt,
  заголовки — оригинальный Museo Sans Cyrl 900 Italic из `source/assets/`.
- `site/content.js` — предварительный сезон, все 15 дней и 11 фотографий.
- `source/pages/` — оригинальные HTML главной и политики без изменений.
- `source/assets/` — оригинальные фотографии, логотипы, шрифты, CSS и JavaScript.
- `source/manifest.json` — адрес, размер и SHA-256 каждого ресурса.
- `scripts/build.mjs` — сборка новой главной, оригинала, политики и `release.json`.
- `scripts/check.mjs` — контроль хешей, локальных путей, состава галерей и расписания;
  обратная замена адресов должна полностью восстановить исходный HTML.
- `tests/site.test.mjs` — часовой пояс, состояния света, качество погодных данных,
  контраст текстовых поверхностей, календарь 2027 и статическое содержание.
- `scripts/update-currency.mjs`, `site/currency.js`, `site/data/currency.json`
  — официальный XML ЦБ, проверка номинала и датированный курс за одну единицу.
- `.github/workflows/pages.yml` — проверка и публикация `main`, а также
  ежедневный выпуск обновлённого курса в 06:15 МСК. Датированная история
  записывается только в отдельную ветку `codex/cbr-data`.
- `docs/migration.md` — границы переноса и особенности оригинала.
- `docs/redesign-rules.md` — обязательные принципы Notion и NN/g, требования
  DD-01–DD-24, постоянная сверка, приоритеты и вопросы
  к организаторам.
- `docs/art-direction.md` — утверждённый замысел «побывать в Анталье до поездки»:
  свет, погода, материалы, движение и исследование времени.
- `docs/redesign-sources.md` — отобранные принципы Notion, рекомендации NN/g,
  технические основания W3C и направление из Bitter Glitter.
- `docs/editorial-redesign.md` — последняя смена стиля, отбор Typedump / Playgrnd
  и конкретные свидетельства сверки с правилами.
- `docs/season-2027.md` — принятые условности, реализация и границы проверки.

`dist/` генерируется и не хранится в Git. Исходный домен не переключается.
При другом адресе публикации передать `SITE_URL` на этапе сборки.

## Основания оформления

[Принципы N01–N08, S01–S11 и требования DD-01–DD-24](docs/redesign-rules.md)
обязательны при работе над сайтом. Сверяться до работы, в прототипе, перед
публикацией и при описании результата: принцип → применение → проверка
и её свидетельство либо ограничение.
[Арт-направление](docs/art-direction.md) закрепляет задачу
дать человеку почувствовать место до решения о поездке, используя примеры
Bitter Glitter и Hotline Camp. Документы связаны с [реестром источников](docs/redesign-sources.md)
и включены в [инструкции проекта](AGENTS.md). Наличие правил и автоматических
проверок не заменяет художественную приёмку или исследование с участниками.

## Обновление оригинальных ресурсов

Команда `python3 scripts/import-assets.py` скачивает ресурсы, на которые ссылаются
сохранённые HTML и CSS. Она нужна только при осознанном повторном импорте.
Обычная сборка и CI полностью используют файлы из Git и не скачивают исходный сайт.

Материалы и оригинальный код сохраняют права их правообладателей;
отдельная лицензия на них этим репозиторием не предоставляется.
