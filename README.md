# DD Camp — авторский лендинг

Локальная сборка сайта [camp.dustydumbbells.com](https://camp.dustydumbbells.com/).
23 октября 2026 пользователь выбрал свою исходную вёрстку целиком и поручил
перенести восстановленную форму с независимым сбором заявок.

Действующая основа — подлинный DD CAMP, Museo, фотографии, красный и синий,
бегущие строки, галереи, календарь и справочная часть исходного сайта.
Подробности и разбор решений — [возврат к оригиналу](docs/original-return-2026-10-23.md).
После завершения формы и таблицы пользователь поручил вернуться к выпуску
этого лендинга и разбору его плюсов и минусов. Границы текущего выпуска —
[подготовка и проверка](docs/release-original-2026-10-23.md).

## Запуск и проверка

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Открыть http://localhost:4173/camp.dustydumbbells/.
Для текущего предпросмотра использован порт 4187. После изменений повторить
`npm run build` и обновить страницу.

```sh
npm test          # сборка, контроль снимков, содержание и поведение обработчика
npm run build    # сборка в dist/
npm run preview  # просмотр уже собранного сайта
```

`SITE_URL` задаёт вложенный путь и адрес публикации. Сборка работает без
скачивания исходного сайта; фотографии, шрифты, стили и виджеты сохранены локально.
`dist/` генерируется и не хранится в Git.

## Форма и Google Таблицы

Подготовлен лист «Заявки» в предоставленной пользователем закрытой таблице.
Один участник или пара записываются в одну строку. Время, ID и статус
позволяют находить и обрабатывать заявки.

Широкое разрешение Apps Script на все таблицы аккаунта отклонено пользователем.
Обработчик переделан на отдельную служебную учётную запись с доступом только
к файлу заявок. Проект `dd-camp-applications`, учётная запись и доступ к одному
файлу настроены; Google Sheets API включён. Пользователь сохранил серверный
ключ, приёмник запущен, реальная доставка и повтор без дубликата проверены.
В таблице оставлены две явно помеченные тестовые заявки: локальная проверка
23 октября и отдельная проверка доставки с GitHub Pages 24 октября.
Код, необходимые настройки, разрешения, проверка и ограничения —
[подключение формы](docs/application-google-sheets-2026-10-23.md).

Секреты хранятся только на сервере в Script Properties. Клиенту нужен только
публичный адрес готового приёмника в `site/application-config.js`.
Успех показывается только после подтверждения записи от Google.
В Tilda заявки из локальной сборки не отправляются.

Рабочая таблица оформлена по запросу пользователя: имя и статус рядом,
основные контакты на первом экране, дополнительные поля и данные партнёра
открыты по замечанию пользователя 24 октября, технические скрыты.
Приёмник согласован с новым порядком всех 18 столбцов.

## Карта и текущие исправления

Вместо вызова Яндекс API с пустым ключом подключена отложенная карта Mapbox.
Публичный ключ `DD Camp production` имеет только `styles:tiles`, `styles:read`
и `fonts:read`; единственный разрешённый URL — опубликованный `map.html`.
Координаты сохранены из исходника: 36.863249, 30.63773 (Коньяалты).
Значение берётся из секрета GitHub Actions `DD_CAMP_MAPBOX_PUBLIC_TOKEN`
только при сборке публикации. В исходниках и локальной сборке ключа нет.

GitHub Pages — рабочий сайт. Когда раздел карты действительно виден в активной
вкладке, он автоматически загружает одну карту. Обычные параметры `v`, `release`
с SHA коммита и известные UTM-параметры не отключают её; неизвестные и повторные параметры
закрывают запуск. После ошибки повтор возможен только по нажатию посетителя.
Localhost, эксперименты, `/direction/`, прямая страница карты и браузер
с `navigator.webdriver` не запускают Mapbox. Для всех браузерных проверок
публичной страницы обязательно использовать `?map=preview`: запросов к Mapbox
нет, габарит раздела сохраняется. Обычный браузер CUA сам по себе не считается
автоматизацией. Не снимать эти ограничения ради тестов.
Загрузки карты на рабочем сайте учитываются тарифом Mapbox.
Основание, сценарии и проверка — [проход 25 октября](docs/typography-mapbox-2026-10-25.md).

Меню, состояния заявки, ссылка из политики, доступность данных партнёра
и границы проверки описаны в [исправлениях 24 октября](docs/repairs-2026-10-24.md).

## Исходники и сохранность

- `site/index.html` — выбранная главная; `/direction/` собирается из неё же.
- `source/captures/2026-10-23/` — новый точный снимок сайта с восстановленной формой,
  манифест 85 ресурсов, в том числе 13 новых/обновлённых файлов. Остальные
  переиспользуются из старого снимка без перезаписи.
- `source/pages/`, `source/assets/`, `source/manifest.json` — неизменный контрольный
  снимок 7 октября: две страницы и 78 ресурсов. Главная доступна на `/original/`.
- `scripts/build.mjs`, `check.mjs` — локализация и контроль обоих снимков.
  Основная страница отличается от свежего снимка адресами, явными адаптерами
  сезона и отправки и невидимыми дополнениями доступности; геометрия сохраняется.
- `scripts/season-markup.mjs` — ранее согласованный сезон 2027, календарные
  дни недели, метаданные публикации, описание и клавиатурный доступ к фотографиям.
- `scripts/application-markup.mjs` — отключение Tilda receiver и подключение
  своего обработчика с сохранением оригинального оформления формы.
- `site/application.*`, `site/application-validation.js`, `site/application-config.js`
  — поведение формы, состояния, проверка и адрес приёмника.
- `backend/google-apps-script/` — независимый приёмник и его явные права.
- `tests/application.test.mjs` — серверная проверка, подтверждение, повтор,
  защита от дублей и область доступа. Проверки не создают живых заявок.
- `site/privacy.css` — ранее согласованный перенос длинного заголовка политики;
  остальной исходный HTML политики контролируется без изменений.

Исходный HTML сохраняет снимок 2026 года без перезаписи. При сборке отдельный
адаптер применяет ранее согласованный сезон 2027 из `site/content.js`:
12–25 октября, третий кэмп, правильные дни недели при прежних занятиях
и времени. Удалено устаревшее сообщение о закрытом наборе. Архивные фотографии
остаются материалами Фетхие 2025 года; это указано в доступных описаниях.
Оформление прежних редакций агента в `site/direction/` и `experiments/`
не является выбранной основой этой главной. Эксперименты не входят в обычную
сборку Pages. Исследования и история решений остаются в `docs/` и `AGENTS.md`.

## Публикация

Репозиторий: <https://github.com/anton-gorokhovatsky/camp.dustydumbbells>.
Существующий Pages: <https://anton-gorokhovatsky.github.io/camp.dustydumbbells/>.
Push в `main` запускает публикацию. Текущее поручение охватывает выпуск
выбранного авторского лендинга на существующий Pages, без новой художественной
редакции. Домен `camp.dustydumbbells.com` остаётся отдельным этапом: без
настройки DNS выпуск Pages не отключает размещение на Tilda.

Перед выпуском обязательны `npm test`, широкий и узкий рендер и затронутые
действия. Успешные проверки не означают художественной приёмки. После выпуска
проверяются workflow точного коммита, публичный `release.json` и поведение
опубликованной страницы.

Материалы и исходный код сохраняют права их правообладателей; отдельная
лицензия на них этим репозиторием не предоставляется.
